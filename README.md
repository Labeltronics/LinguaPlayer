# Cyber80 Players

Windows x64 video/audio player with dual independent windows, playlists, fullscreen/PiP, native 10-band EQ and saved presets, anaglyph 3D, scene tools, playback profiles, subtitle checkpoints, Gemini translation, optional local Whisper/Ollama adapters, and HD/FHD/4K export.

See [README_ID.md](README_ID.md), [QUICK_START_ID.txt](QUICK_START_ID.txt), and [the audit](AUDIT_CYBER80_PLAYERS_ID.md). The repository retains the original LinguaPlayer name. API keys and user media must never be committed. GPU/model-dependent features require compatible hardware, drivers or separately installed local services; the application does not promise universal codec coverage or perfect AI translation.
