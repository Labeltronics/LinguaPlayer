PEMBARUAN MODERN + SUBTITLE ATTACHMENT
Baca PEMBARUAN_CYBER80_ID.md untuk seluruh perubahan dan batas pengujian.
Personalisasi: tema/skin, aksen, simpan layout dan mode sederhana.
Playback Pro: chapter, frame berikutnya, aspect/crop, rotasi, output audio dan koleksi.
Subtitle latar belakang: pilih video attachment, lokasi SRT, tunggu notifikasi. Aplikasi harus tetap berjalan.
Proxy MP4 untuk format lain/file besar atau track audio pilihan. Tidak ada API key tertanam.

CYBER80 PLAYERS — PANDUAN WINDOWS

1. Ekstrak SELURUH ZIP ke folder baru. Jalankan Cyber80Players.exe.
   Jangan pindahkan EXE sendirian: folder _internal wajib menyertainya.
2. Buka media menerima video dan audio. Tambah film/+Film dapat memilih banyak file.
   Playlist: drag untuk mengurutkan, hapus pilihan, repeat/shuffle, simpan/buka M3U8/JSON.
   Tambah folder tersedia di menu File. Cari nama/lokasi di panel playlist.
3. Full screen (F11) ada di dekat Play/PiP. Esc kembali.
   Space Play/Pause; M Mute; kiri/kanan mundur/maju 5 detik;
   atas/bawah maju/mundur 1 menit; PageUp/PageDown pindah media.
   Kecepatan 0,25–4x. Shortcut tidak mengambil alih penyuntingan kolom/tabel/playlist.
4. Pemutar kedua membuka jendela independen dan dimulai dalam keadaan mute.
   PiP menampilkan jendela kecil always-on-top dengan kontrol dan subtitle.

AUDIO STUDIO
- Klik Equalizer atau menu Audio. Centang Aktifkan equalizer.
- Pilih salah satu dari 13 preset: Normal, Film seimbang, Film aksi, Dialog/Vokal,
  Musik seimbang, Rock, Pop, Jazz, Klasik, Bass, Treble, Headphone, Malam/Lembut.
- Geser 10 band native VLC dan preamp (-20 sampai +20 dB). Bypass mengembalikan suara asli.
- Auto-headroom mengurangi preamp saat ada boost. Ini bukan limiter/kompresor.
- Simpan preset pribadi; impor/ekspor profil JSON. Pengaturan otomatis tersimpan per jendela.
- Muat track untuk memilih track audio playback, pilih kanal atau sinkron audio +/-5 detik.
  Pilihan track playback belum mengganti track default yang diproses oleh AI.

CINEMA / SCENE TOOLS
- Bookmark dan daftar bookmark: simpan/pilih adegan. Klik dua kali untuk menuju adegan.
- A-B repeat: klik pertama A, kedua B, ketiga menghapus loop.
- Screenshot menyimpan PNG. Pada 3D menyimpan frame anaglyph; pada mode native memakai snapshot VLC.
- Posisi menonton tersimpan berkala. Profil film menyimpan suara, warna, renderer, 3D,
  subtitle dan kecepatan. Profil dapat diterapkan otomatis saat file yang sama dibuka.
- Poster lokal: letakkan JPG/PNG dengan nama sama seperti media, atau poster.jpg di folder media.
- Thumbnail muncul saat slider digeser. Info codec menampilkan metadata/statistik dan dukungan FFmpeg.
- GPU Cinema meminta akselerasi D3D11 pada Windows. Ketersediaan GPU/driver tidak dijamin.
- Warna video, gamma, ketajaman, font/warna/offset subtitle dan pencarian teks tersedia.
- Ekspor HD 720p, Full HD 1080p, atau 4K 2160p membuat MP4 baru.
  CPU memakai Lanczos dan ketajaman; NVIDIA/Intel menyediakan jalur GPU bila tersedia;
  AMD AMF memakai encoder GPU dengan skala CPU. Padding/transfer memori dapat memakai CPU.
  Upscale bukan AI super-resolution dan tidak memulihkan detail hilang.
  Efek 3D dan overlay subtitle tidak dibakar pada file ekspor.

3D
- Setelan 3D: aktifkan, pilih merah-cyan atau merah-biru sesuai kacamata.
- Sumber 2D: pergeseran bidang buatan. Stereo objek asli memerlukan SBS/TB.
- Pilih half/full sesuai sumber, geser tiap mata minus/plus, atau tukar mata.
- Render anaglyph memakai CPU, maksimal 960x540; file asli tidak diubah.

SUBTITLE GEMINI / AI LOKAL
1. Klik Subtitle / AI. Default Gemini online, target Indonesia, sumber bahasa auto-detect.
2. Masukkan key Gemini Free Tier tanpa billing, lalu Simpan API key di Windows.
   Key lama LinguaPlayer masih dapat dibaca. Key tidak ditanam dalam EXE/proyek/cache.
3. Isi kamus nama/istilah bila perlu, lalu Buat/Lanjutkan subtitle.
4. Potongan 10 detik memakai konteks overlap 1 detik. Pemutaran menunggu buffer bila API lambat.
5. Hasil parsial disimpan atomik ke cache lokal, dapat dilanjutkan setelah restart dengan file
   dan konfigurasi yang sama. Hasil lengkap dipakai ulang tanpa panggilan API.
6. Edit teks/timing, cari kalimat, simpan proyek JSON atau ekspor SRT untuk offline.
   SRT dengan nama sama di folder media dapat dimuat otomatis.
7. Hapus cache konfigurasi saat ini untuk memproses ulang. Batal pada permintaan aktif
   menunggu timeout (maksimal 180 detik per permintaan); error sementara dicoba maksimal dua kali.
8. AI lokal memerlukan server Whisper.cpp dan Ollama/model terpasang terpisah.
   Baca AI_LOKAL_ID.md. Aplikasi tidak mengunduh bobot model secara otomatis.

BATASAN DAN PENGUJIAN
- Runtime VLC/FFmpeg, plugin dan library dibundel. Tidak perlu memasang Python/VLC terpisah.
- Tidak ada fallback otomatis ke layanan berbayar. Status billing tidak dapat diverifikasi dari key.
- Free Tier, kuota, dukungan model, jaringan dan kualitas subtitle tetap bergantung layanan.
- Codec aktual mengikuti VLC; DRM, file korup atau codec khusus dapat gagal.
- HDR native bergantung VLC, Windows, monitor dan driver; belum dikalibrasi aplikasi.
- GPU fisik tidak diverifikasi pada mesin CI. Periksa Info codec dan log jika ada masalah.
- Log video dapat memuat nama/lokasi file. Cache subtitle disimpan sebagai teks lokal tanpa enkripsi.
- EXE belum bertanda tangan digital. Installer/update otomatis belum tersedia.
- Baca AUDIT_CYBER80_PLAYERS_ID.md dan HASIL_UJI_WINDOWS.json untuk cakupan/hasil uji.
